## G1

fix: 修復座位鎖在元件卸載時未及時釋放

添加 cancelled 旗標確保續期定時器在卸載時立即停止執行，並在清理函數中顯式呼叫 releaseLock 確保伺服端正確釋放座位鎖。

## G2

為 API 請求加入自動重試機制，對於 502、503、504 等暫時性伺服器錯誤自動重試最多 3 次，使用指數退避策略（200ms → 400ms → 800ms）。其他狀態碼或超過重試上限時立即失敗。

驗證方式：模擬 502/503/504 錯誤確認重試行為、驗證其他狀態碼無重試、檢查延遲增長。

## G3

啟用後會在一次 render 內自動去重相同請求，所有重複查詢共享同一 response 而不重複發送。暫存結果存於 request 層級快取，render 結束後清空。這可大幅減少不必要的 API 呼叫，改善頁面載入效能。
